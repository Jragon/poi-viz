# Quarter-time as a live notebook cell

The immediate question is not whether we can enumerate every quarter-time pattern. It is whether a poi idea can sit inside a written experiment with enough context around it to be useful later.

## Question

Can the visualizer behave like an embedded lab instrument: one live pattern, a little transport, a little projection control, and enough surrounding prose to record what the pattern is trying to show?

## Setup

This first exhibit preserves the pasted authored pattern as-is. It has seven left-hand segments and seven right-hand segments, moves across wall, wheel, and floor planes, and uses the current atomic plane-break compiler rather than a special journal-only path.

## Observations

This is deliberately closer to a notebook than a polished demo. The useful thing is the placement: the motion is not off in a separate tool, and the writing is not detached from the motion. The visualizer becomes part of the argument.

The first constraint to keep honest is that the page should not become the main app again. It needs inspection controls, but not export workflows, document selection, webcam state, or metronome rules.
